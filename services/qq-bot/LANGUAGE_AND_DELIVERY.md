# QQ 语言与投递契约

本文件维护 QQ 的语言选择、查询和定时恢复规则。入口见 [README](README.md)，
从该入口查看运行配置与升级步骤。代码完成与正式群验收分别记录。

## 统一语言规则

`qq.groups[].languages` 是该群所有输出的唯一语言来源，支持 `zh-cn`、`en-us`、`ja-jp`、`ko-kr`，
必须非空、不重复；顺序就是输出顺序。查询、帮助、玩法、等待提醒、玩家榜、连胜、月报及错误反馈均遵循它。
房间名、玩家 ID、卡片 ID、数字、品牌和命令语法保留原值。

每张战绩图、卡片图和月报图同时显示全部所选语言，标题、名称、表头、轴标题、口径说明和生成时间标签均一致。
单语言群不会额外显示英语/日语；多语言图增加高度以容纳内容，仍保持完整月报四张图。
卡片名称按所选语言调用公开 API，核对卡片 ID、顺序、计数和覆盖样本后合并；不现场翻译卡名。
API 缺失某种名称时沿用提供者的回退值。各语言查询正文的官网链接使用对应 `L=zh|en|ja|ko`。

月报缓存以月份和有序语言列表区分，素材模型包含语言列表，各版本有独立批次哈希。
投递开始后固定该批次与正文；中途修改语言配置不会混用旧图与新文案，下一次新查询或新一期投递使用新配置。
Discord 的完整四图/X 导出仍用原英日格式，连胜仍用原四语规则；QQ 不开放个人语言覆盖参数。

## 查询命令

| 命令 | 行为 |
| --- | --- |
| `@机器人 月报`、`/meta` | 上月完整四图 |
| `@机器人 月报 2026-09`、`/meta month:202609` | 指定月完整四图 |
| `@机器人 卡组 202609`、`/meta month:202609 view:decks` | 卡组使用率 Top 15、总体 Match 胜率、15×15 对阵矩阵 |
| `@机器人 卡片 副卡 202609`、`/meta month:202609 view:side` | 单项卡片 Top 10：`monster/spell/trap/extra/side` 或 `怪兽/魔法/陷阱/额外/副卡` |

月份沿用源码 `bot-core/MONTHLY_REPORT_DESIGN.md` 的月报数据规则：默认上月，支持 `YYYY-MM`/`YYYYMM`，
拒绝未来或非法月份；当月显示进行中。统计分母、细分类 ID、矩阵方向和小样本规则保持不变。
QQ 不接入管理员预览、手动补发、X 素材导出或固定状态卡。
四图回复将摘要放在首张图片的正文中，后续顺序为怪兽、魔法/陷阱、额外/副卡。
发送前校验总回复数不超过五条，避免发送成功摘要后才发现回复额度不足。

## 每日榜与月报恢复

`QqScheduler` 分别管理每日榜和月报，持久状态文件独立。

- 每日榜：北京时间 04:00 到当日午夜补漏；明确失败一分钟后重试，不补过去日期。
- 月报：每月 1 日北京时间 10:00 发布上月，默认 72 小时恢复窗口；明确失败五分钟后重试。
- 每群/每期独立保存正文、素材批次、各部分消息 ID 和下一部分序号。一群失败不阻塞其他群。
- 月报先上传图片（`srvSendMsg: false`），再保存 `sending`，最后请求发送并保存回执。
  已确认送达的图片不会重复发送，上传/取 Token 失败可以重试。
- 请求明确被平台拒绝时保留 `pending`。网络超时、回执缺失、发送后保存失败，以及重启发现 `sending`，
  均标记 `uncertain` 并暂停该群该期余下部分，不自动重试结果不明的消息。这是用户确认的防重复策略。
- 旧 `lastAttempt` 不能证明成功；迁移时该日期在各目标群标为 `uncertain`，不盲目补发。
- 无数据不发空月报；暂未连接、`temp` 未解析、主动开关关闭或权限被拒绝的群不消耗投递进度。

QQ 群消息接口没有本服务可用的历史回读确认能力，因此这里不承诺和 Discord 相同的超时恢复。
`uncertain` 需人工核对真实群消息；本轮没有新增手动补发命令。保持状态与素材，不能用删 `data/` 的方式解决。
群语言配置、发送消息域名及主动权限仍需真实群验收，配置开关不会申请平台权限。

## 源码模块

| 职责 | 入口 |
| --- | --- |
| QQ 连接、群发现、路由与主动权限 | `src/qq.mjs` |
| 命令语法与公开查询白名单 | `src/commands.mjs` |
| 回复预算、图片/文字发送与回执分类 | `src/messages.mjs` |
| 固定投递正文/素材与发送前准备 | `src/scheduled.mjs` |

| 数据校验、语言缓存键与素材归档 | `../bot-core/src/monthly-report.mjs` |

源码目录需要 `../bot-core`；独立部署包将这些模块复制到自身 `src/core/`。
